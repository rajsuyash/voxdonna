### Measure business value and avoid false wins

- Establish actual referral traffic, successful enquiries and qualified workflow requests using the existing analytics/CRM; unavailable data stays unavailable. Track country, buyer role and requested task where collected appropriately.
- Record links at the source-page level: live status, context, final destination and `rel`. A relevant nofollow mention may send better buyers than a followed link from a bulk list.
- Separate independent earned links, existing-citation repairs, owned profiles and paid/sponsored visibility. Never count a corrected listing as a new domain or multiple sitewide links as multiple endorsing companies.
- Review whether new enquiries concern custom employees and non-voice workflows as well as voice. Broad positioning is succeeding only when buyers understand the broader offer.
- Use Search Console query/page changes as supporting evidence when accessible. Content changes, indexing and outreach occur together, so do not attribute ranking movement to a single link without stronger evidence.
- If tailored pitches get no substantive replies, check audience fit and asset usefulness before increasing volume. If links generate visits without enquiries, inspect the offer and conversion path. If pages cannot be crawled or indexed, resolve that issue before scaling distribution.

Do not buy PBN placements, automated backlinks, reciprocal link packages or directory bundles. Google identifies manipulative links as [link spam](https://developers.google.com/search/docs/essentials/spam-policies#link-spam).
